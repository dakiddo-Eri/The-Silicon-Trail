# The-Silicon-Trail

This game is based on The Oregon Trail game, but in the future and AI.
hehehe

In the year 2029, most datacenters now power AI, taking up all the space for
other important datacenters and other buildings for people. You are assigned
a job to carry a stick of DDR6 32 GB of RAM to a health datacenter that has
been recently shutdown because of an AI hallucination. 

## Features
* **Zero External Libaries:** Runs 100% using only built-in Python modules
* **High-stakes Survival:** Juggle your Miles, cash and sanity, really think this is easy??
* **Unhinged Encounters & Permaeath:** Survive rogue AI and crazy scenarios!!
* **Buy some secret `White Monster`, gulp that all down and cook the entire way!!

## How to Play

### Option 1: Run the scary Windows .exe
1. Go to the **[Releases](../../releases)** tab
2. Download `main.exe`
3. Launch it! It should open your terminal!

### Option 2: Run with Python (for all platforms :3)
Make sure you have **Python 3** installed, then download the source or clone this repository

1. python3 main.py
yay its running now :3

## Controls & Tips
* Type the number to your choice, (`1`, `2`, `3`, etc.) and press **Enter**
* **Watch your stats:** Buy secret contraband early, it can save your life later, trust
* **Think twice before handing over the RAM.**

## Notes
* Because the `.exe` is unsigned, a warning thingy will pop up yea, if you think this is sketchy delete it if you want, but if you're confident, just say run anyways or if theres no button like that yea, download the source and run `main.py`.
